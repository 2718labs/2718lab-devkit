仓库根/
├── pyproject.toml
├── uv.lock                      # 跨平台锁文件,必须进 git
├── .python-version              # 钉住解释器版本,如 "3.12"
├── .gitignore                   # 必须包含 .venv/
├── README.md
├── src/
│   └── <package_name>/          # 与 pyproject [project.name] 对应(连字符→下划线)
│       ├── __init__.py
│       └── ...
└── tests/
    ├── __init__.py
    └── test_<module>.py         # test_*.py 命名,pytest 默认发现规则

说明:
- src-layout 把包代码放进 src/ 而不是仓库根,防止未安装状态下也能被意外 import 到"看似能跑",
  也能在打包时更早暴露"漏打包某个文件"之类的问题。
- 只跑 `uv run` 的脚本/应用允许 flat-layout:代码直接放仓库根或简单子目录,不强制这棵树。
- .venv/ 不出现在这棵树里,因为它必须只存在于本地/CI,不进版本控制。
