## 配置

与 `_conf_schema.json` 保持一致,每新增/修改一个配置项都要同步更新这张表。

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `example_field` | string | `""` | 示例字段,替换成真实配置项 |

## 安装

1. 将本插件目录放入 `AstrBot/data/plugins/` 下。
2. 在 AstrBot WebUI 中重载插件,或重启 AstrBot。
3. 如有配置项,先在 WebUI 里填好配置再启用。
