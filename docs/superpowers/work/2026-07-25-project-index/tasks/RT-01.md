# RT-01 Durable Data Root Fallback

Owner: sol-ultra-runtime
Depends on: none

## Goal

Make `2718lab-tools` usable when Codex does not supply any optional data-root
environment variable.

## Context

- `.mcp.json` `env_vars` entries only pass existing values; they do not define
  `CODEX_HOME`.
- Preserve explicit root priority and rejection of plugin source/cache paths.
- The deterministic fallback is `Path.home() / ".codex" / "data" /
  "2718lab-devkit"`.

## Write Scope

- `mcp-tools/server.py`
- `mcp-tools/tests/test_mcp_contract.py`
- `README.md`

## Steps

1. Change the existing data-root contract test first. Patch `Path.home()` to a
   D-drive temporary home, clear the environment, and assert the fallback path.
   Assert a real wrapper call returns `NOT_FOUND`, not
   `DATA_ROOT_UNAVAILABLE`, and creates durable SQLite below that fallback.
2. Run the single test and record RED against the current implementation.
3. Implement the fallback while preserving `BUGKILLER_HOME -> PLUGIN_DATA ->
   CODEX_HOME/bugkiller` priority and all source/cache rejection checks.
4. Document the fallback briefly in README; do not add WebUI or setup steps.
5. Run the focused test and all `mcp-tools/tests`.

## Acceptance

With no root environment variables, `workflow_status("missing")` returns the
stable business error `NOT_FOUND`, the data directory is outside plugin source
and cache, and explicit environment roots still win.

## Return

Changed files, RED/GREEN output, resolved fallback path, and blockers. Do not
commit, push, or create a PR.
