# QG-01 Ruff Quality Gate

Owner: sol-ultra-quality-gate
Depends on: RT-02, IDX-04C

## Goal

Make the plugin runtime and tests pass the repository-wide Ruff lint and format
checks without changing behavior.

## Context

- Input snapshot is established by `project_index_query` and its `trace_id`.
- Preserve all existing behavior and test coverage.
- Do not modify Markdown, manifests, agents, or workflow policy.

## Write Scope

- `hooks/metadata_guard.py`
- `mcp-tools`

## Steps

1. Run Ruff lint and format checks and record the failing files.
2. Apply only deterministic formatter output and minimal lint fixes.
3. Run the same checks and the full MCP test suite.

## Acceptance

- `project_index_sync`
- `strict_index=true`
- `project_index_query`
- `trace_id`
- `worktree_checkpoint_create`
- `project_index_sync(bind_as="output")`
- output `project_index_query` and output `trace_id`
- `workflow_artifact_register(kind="verification", snapshot_id=...)`
- `workflow_complete`
- `python -m ruff check mcp-tools hooks/metadata_guard.py` exits zero.
- `python -m ruff format --check mcp-tools hooks/metadata_guard.py` exits zero.
- `python -m pytest mcp-tools/tests -q` exits zero.

## Return

Changed files, exact commands and outputs, conclusion, and blockers.
