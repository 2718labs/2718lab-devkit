# RT-02 Stdio-Safe Git Probes

Owner: sol-ultra-stdio-fix
Depends on: IDX-03

## Goal

Prevent project-index Git probes from inheriting the MCP stdio input pipe on
Windows.

## Context

- A real stdio `project_index_sync` hangs inside `_git_head()`.
- A faulthandler trace shows `subprocess.run(...).communicate()` waiting after
  the Git timeout while descendant pipe handles remain open.
- A diagnostic-only `stdin=subprocess.DEVNULL` injection makes the same stdio
  call return `INDEX_READY` immediately.

## Write Scope

- `mcp-tools/project_index/service.py`
- `mcp-tools/project_index/checkpoints.py`
- `mcp-tools/tests/test_project_index_core.py`
- `mcp-tools/tests/test_project_index_checkpoints.py`

## Steps

1. Add failing tests proving every project-index Git probe supplies DEVNULL.
2. Add the minimum subprocess arguments to both Git probe boundaries.
3. Run core, checkpoint, MCP contract, and real stdio smoke tests.

## Acceptance

Git probes never inherit protocol input; existing snapshot/worktree behavior
is unchanged; real stdio sync and query return within the bounded timeout.

## Return

Changed files, RED/GREEN output, stdio evidence, and blockers.
