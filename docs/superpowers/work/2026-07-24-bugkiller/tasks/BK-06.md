# BK-06 Package, Validate and Install

Owner: terra-release
Depends on: BK-03, BK-05

## Goal

Update plugin metadata/docs, run the full suite, synchronize the long-term source and configure current Codex.

## Context

Read `contracts/host-boundaries.md`. External commit, push and PR are separate manual gates.

## Write Scope

- `.codex-plugin/plugin.json`
- `.claude-plugin/plugin.json`
- `README.md`
- `<long-term-source>/2718lab-devkit`
- `agents/bugkiller-*.md`
- `agents/openai.yaml`

## Steps

1. Write failing metadata consistency tests, then set version `0.2.0` and describe executable orchestration.
2. Run all unit, work-package, skill and MCP validators with D-drive temp/cache paths.
3. Copy only verified source files to the long-term 2718lab directory; do not copy `.git`, caches, DBs or evidence.
4. Refresh the current Codex plugin configuration through the plugin update/cachebuster flow and verify plugin-bundled agents in a new Codex task; do not write `~/.codex/agents`.

## Acceptance

All tests pass; work package validates; new task discovers `bugkiller`, plugin-bundled agent definitions and orchestration MCP tools. Report any restart/new-task requirement rather than claiming hot reload.

## Return

Changed/synchronized paths, exact validation evidence, plugin refresh result, remaining host compatibility limits and requested external gates.
