# BK-01 Bugkiller Domain Policy

Owner: terra-policy
Depends on: none

## Goal

Implement Bugkiller states, risk routing, model budgets, evidence redaction and canonical hashes.

## Context

Read `contracts/bugkiller-policy.md` and `contracts/host-boundaries.md`.

## Write Scope

- `mcp-tools/bugkiller/__init__.py`
- `mcp-tools/bugkiller/models.py`
- `mcp-tools/bugkiller/state_machine.py`
- `mcp-tools/bugkiller/policy.py`
- `mcp-tools/bugkiller/redaction.py`
- `mcp-tools/tests/test_bugkiller_policy.py`
- `mcp-tools/tests/test_bugkiller_redaction.py`

## Steps

1. Write failing tests for low-risk direct completion and high-risk user gates.
2. Keep Sol budget zero until an explicit approved escalation record exists.
3. Implement canonical JSON/SHA-256 and bounded redaction for tokens, headers, PEM blocks and URL credentials.
4. Keep `DEGRADED_TRIAGE` as a flag and `RESUMED` as an event, not case states.

## Acceptance

Run `python -m unittest mcp-tools/tests/test_bugkiller_policy.py mcp-tools/tests/test_bugkiller_redaction.py -v`; ordinary cases request neither reviewer nor Sol.

## Return

Changed files, policy rules, redaction coverage, test output and open risks.
