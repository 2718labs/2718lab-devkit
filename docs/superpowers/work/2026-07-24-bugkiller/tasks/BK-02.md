# BK-02 Language and Command Profiles

Owner: terra-adapters
Depends on: BK-01

## Goal

Detect Python, TS/JS, Rust and Go projects and return deterministic command specs.

## Context

Read `contracts/bugkiller-policy.md` and `contracts/host-boundaries.md`.

## Write Scope

- `mcp-tools/bugkiller/adapters.py`
- `mcp-tools/tests/test_bugkiller_adapters.py`

## Steps

1. Write failing fixture tests for each language, mixed repositories and conflicting JS lockfiles.
2. Define immutable executable/args/cwd/env/network/timeout/output-limit specs.
3. Never emit shell strings, redirects, command substitution or unresolved globs.
4. Mark dependency installation, lifecycle scripts and network as gated actions.

## Acceptance

Run `python -m unittest mcp-tools/tests/test_bugkiller_adapters.py -v`; unknown/conflicting build systems return a structured blocked reason.

## Return

Changed files, detection precedence, allowed commands, test output and unsupported layouts.
