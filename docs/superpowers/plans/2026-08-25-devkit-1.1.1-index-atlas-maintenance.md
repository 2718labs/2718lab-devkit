# DevKit 1.1.1 Index and Atlas Maintenance Implementation Plan

## Scope

Implement the approved local-only corrective slice. Remote Atlas authority is
recorded as a future seam and is not implemented.

## Task 1: Freeze baseline and version contract

- Add release/version assertions for 1.1.1.
- Record the focused Index/Atlas baseline.
- Keep historical 1.1.0 planning references unchanged.

Verification: focused release metadata tests.

## Task 2: Index retention schema and preview

- Add a failing migration/reopen test for retention metadata.
- Add failing tests that identify only unprotected old snapshots.
- Implement a deterministic preview object and store query.
- Ensure unknown references and schema mismatches return zero candidates.

Verification: project-index core retention tests.

## Task 3: Atomic retention apply

- Add failing tests for preview-token mismatch, concurrent new references,
  active/latest/rollback protection, and bounded batch deletion.
- Implement immediate-transaction revalidation and snapshot deletion.
- Return a receipt with candidate and actual deletion counts.
- Do not run full foreground vacuum.

Verification: retention unit tests plus existing index workflow tests.

## Task 4: Runtime maintenance entry

- Add a local preview/apply command rather than an implicit startup or post-sync
  deletion hook.
- Collect Orchestrator snapshot roots and hold its writer fence while apply
  revalidates and deletes a bounded Index batch.
- Keep bootstrap, sync, and query paths free of hidden retention deletion.

Verification: runtime composition and MCP contract tests.

## Task 5: Atlas local activation

- Add a failing runtime test proving bundled recipes are queryable after fresh
  bootstrap.
- Add a failing reopen test proving one accepted local recipe is selected on a
  later equivalent request.
- Repair only the missing bootstrap, CAS-root, loader, or composition wiring.
- Reuse existing validation, ingestion, matching, and acceptance machinery.

Verification: Atlas runtime, service, store, promotion, and acceptance tests.

## Task 6: Version, documentation, and cleanup

- Set plugin, Python project, lockfile, README, changelog, issue template, and
  release assertions to 1.1.1.
- Document Index disposal versus Atlas durability and the future
  server-authoritative Atlas boundary.
- Remove only confirmed inactive generated Ruff/Pytest caches. Preserve the
  reusable virtual environment and all unrelated dirty work.

Verification: release workflow, primary artifact, and governance tests.

## Task 7: Final verification

- Run affected tests, then the full locked test suite.
- Run Ruff check/format, Pyright, and Python compile checks.
- Build the versioned plugin artifact outside the source tree on G:.
- Review Git status and diff; independently verify no remote Index behavior and
  no deletion outside the owned index database/caches.
