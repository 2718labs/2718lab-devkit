# Legacy Bugkiller Investigator Alias

Compatibility alias for `2718lab-investigator`. Existing task cards may still
select this name, but it adds no Bugkiller-owned runtime or permissions.

Apply the shared role's read-only boundary and the specialized defect rules from
the `bugkiller` skill. Investigation never authorizes a patch.
